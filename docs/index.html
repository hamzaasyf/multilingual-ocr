Languages to look for

Each line is read by every model switched on and the best reading wins. Models download once from Hugging Face and are then cached by your browser.

Display
01 · Detect

Find text lines

PP-OCRv3 DB detector draws a probability map of where text is, then each blob becomes a line box.

02 · Recognise

Read each line

Each line is resized to 48 px high and read by PP-OCR recognisers with CTC decoding.

03 · Pick language

Best match wins

Every enabled model reads the line; confidence and coverage decide which reading is kept, and letters and common words name the language.

04 · Fix order

Right-to-left aware

Arabic is put back into reading order and Hindi vowel signs are moved to the right place.
